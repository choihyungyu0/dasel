# VAL-01 기존 태양광 설치 라벨 — 판독 기록

이 폴더(`data/labels/`)에는 **사람이 검수한 라벨**만 둔다. AI 판독은 `data/labels_ai/final.csv`에 있다.
파일 형식은 둘 다 `bld_id,label,labeler,image_year` (label = 설치 / 미설치 / 불명).

## AI 판독 (data/labels_ai/final.csv)

| 항목 | 내용 |
|---|---|
| 대상 | 30kW 이상 대상 건물 336동 |
| 영상 출처 | 브이월드(국토교통부) 위성영상 WMTS(Satellite 레이어) |
| 촬영연도 | 확인 안 됨 — 브이월드 타일은 촬영일을 내려주지 않는다. 그래서 `image_year`는 비워 두었다 |
| 영상 수집 | `scripts/label_tiles.mjs`로 건물마다 지붕 외곽선(노란 선)을 올린 화면을 캡처 (2026-10-03~04) |
| 판독 모델 | Claude Opus 5.5 (`claude-opus-5-5`), Claude Code 세션 안에서 이미지 판독 |
| 판독 일시 | 1차·2차 판독 2026-10-03~04, 재판독 2026-10-04 |
| 판독 방식 | ① 12동씩 모은 시트(`scripts/label_sheets.py`)를 두 번 따로 판독(`data/labels_draft/ai_pass1_n.txt`, `ai_pass2_n.txt`) ② 두 결과가 엇갈리거나 불확실한 61동은 640px 확대 이미지로 다시 판독(`ai_review_n.txt`) ③ `scripts/label_draft.py`가 재판독 > 두 판독 일치값 순으로 합쳐 `final.csv`를 만든다 |
| 결과 | 설치 42 · 미설치 261 · 불명 33 |

### 판독 지시문(프롬프트)

> 노란 외곽선 안 지붕만 본다. 각 건물을 아래 셋 중 하나로 표시한다.
> - 설치: 지붕에 태양광 패널(짙은 남색·검정 격자가 줄지어 있는 면)이 보인다. 지붕 일부만 덮어도 설치.
> - 미설치: 지붕 전체가 보이고 패널이 없다. 채광창(가는 줄무늬), 짙은 색 금속 지붕, 옥상 설비는 패널이 아니다.
> - 불명: 영상이 흐리다, 건물이 아직 없다(공사 중·나대지), 그림자에 가려 판단할 수 없다.
> 외곽선 밖(이웃 건물, 중정)의 패널은 세지 않는다.

### 눈가림 재판독 (data/labels_draft/ai_blind_queue.csv)

검수 표본 92동(아래 '사람 검수' 큐와 같은 건물)을 별도의 Claude Opus 5.5 에이전트가 2026-10-04에 다시 판독했다. 앞선 판독 파일을 열지 않았고, 건물 순서를 섞어(시드 7) 번호를 새로 붙인 640px 시트로 봤다. 결과는 90/92 일치('설치' 42동 모두 유지, '미설치' 표본 50동 중 '설치'로 바뀐 것 0, '불명'으로 바뀐 것 2). 엇갈린 2동은 '불명'으로 내려 계산에서 뺀다. 이것도 AI 판독이며 사람 검수가 아니다.

### 한계

- 두 번의 판독과 재판독 모두 같은 모델이 했다. 서로 독립된 검수가 아니다.
- 부분 설치, 짙은 색 금속 지붕, 채광창은 틀릴 수 있다.
- '불명' 33동은 대부분 위성 타일이 흐리게 나오거나 건물이 아직 없는 터다.

## 사람 검수 (이 폴더)

- 검수 표본(큐): AI가 '설치'로 본 건물 전부 + '미설치' 중 무작위 50동(시드 20261004). 목록은 `public/data/label_queue.json`.
- 라벨링 화면(`/label`)이 이 큐를 먼저 보여 준다. 끝나면 CSV를 내려받아 이 폴더에 넣고 `npx tsx scripts/06_validate.ts`를 실행한다.
- 스크립트가 계산하는 것: AI 판독과 사람 검수의 일치율, 정밀도(AI '설치' 중 사람도 '설치'), 재현율, AI '미설치' 표본에서 놓친 비율.
- 검증 지표(상위 10%·20% 설치 비율, Mann-Whitney U)는 사람이 본 건물은 사람 라벨로, 나머지는 AI 판독으로 계산한다. 큐를 다 보기 전에는 화면에 '검수 전' 배지가 붙는다.
